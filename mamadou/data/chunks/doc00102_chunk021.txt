( see for example the logic program for computing fibonacci numbers in algorithm = logic + control ). in contrast with the inefficiency of forward reasoning in this example, backward ( or " top - down " ) reasoning using sld resolution turns the logic into the euclidean algorithm : to find the gcd c of two given numbers a and b : if a = b, then c = a. if a > b, then let a ' = a - b and find the gcd of a ' and b, which is c. if b > a, then let b ' = b - a and find the gcd of a and b ', which is c. one of the advantages of the logic programming representation of the algorithm is that its purely logical reading makes it easier to verify that the algorithm is correct relative to the standard non - recursive definition of
