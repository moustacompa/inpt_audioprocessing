TACHE 4 -- Entrainer le Dual Encoder (1 epoque pour tester)
------------------------------------------------------------------------------
[ ] Creer le dossier de sortie si absent
    > mkdir models\dual_encoder_mpnet

[ ] Lancer l'entrainement en mode rapide (1 epoque, batch 32)
    > python -m training.train_dual_encoder \
        --precomputed-text-npy      embeddings/precomputed_text.npy \
        --precomputed-text-manifest embeddings/precomputed_text_manifest.csv \
        --pairs-csv            data/output/pairs_train.csv \
        --val-pairs-csv        data/output/pairs_val.csv \
        --audio-manifest-csv   embeddings/audio_embeddings_index.csv \
        --audio-embeddings-npy embeddings/audio_embeddings.npy \
        --output-dir           models/dual_encoder_mpnet \
        --projection-dim       256 \
        --epochs               1 \
        --batch-size           32 \
        --num-workers          0

[ ] Verifier le checkpoint cree
    - models/dual_encoder_mpnet/best_model.pt

Attendu :
    [INFO] Mode RAPIDE : embeddings texte pre-calcules
    Debut de l'entrainement : 1 epoques | ...
    [Epoque 1/1] loss=... | Recall@5=... | MRR=...
    Entrainement termine. Meilleur MRR=... -> models/dual_encoder_mpnet/best_model.pt
